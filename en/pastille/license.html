5. User data

The Software works locally: clipboard history (texts, images and links to files), the anonymization dictionary and settings are stored on the User's device, encrypted with Windows mechanisms, and are not sent to the Owner. For a screenshot that Windows has already saved in the User's folder, the Software keeps only a link to that file, which it never modifies or deletes. The Privacy Policy, available in the Software ("About"), on the Microsoft Store listing and at https://solutionspasserelleti.ca/en/pastille/privacy.html, describes this processing.

The User remains solely responsible for the content they copy, paste, keep or send, including to third-party services (search engines, artificial intelligence tools, etc.). Anonymization is an aid. In the Software, "anonymize" means reversible masking (pseudonymization): the original values stay in the User's dictionary, on their device, and text masked this way is not anonymized information within the meaning of the law. Masking relies on the User's dictionary and on automatic detection that does not recognize all personal information (in particular addresses, dates of birth and medical information). Shield mode has the same limits and masks only text, not images; in addition, pasting immediately after copying may paste the original text. Shield mode also restores to real values the codes in a copied text, including an instruction the User wrote with codes; a notification reports it. However, it never automatically restores social insurance numbers, health insurance card numbers, payment card numbers, bank account numbers (IBAN) or social security numbers, nor a code placed in a web address: the User restores them on demand. The User must review the text before sending it.

A User who uses the Software for their work must make sure this use is allowed by their employer, their professional regulatory body and the rules that apply to the information they handle (professional secrecy, health information, payment card data, etc.).

Depending on its settings, Windows may also keep copied content (clipboard history, sync across devices). These features are Microsoft's, not the Software's.
